# 🎨 Lumo StoryLab

Lumo StoryLab is an AI-powered app that transforms ebooks into illustrated visual content automatically.

Upload your DOCX file and generate images by chapter — perfect for storytelling, KDP publishing, and content creation.

---

## 🚀 Features

- Upload DOCX ebooks
- AI-generated illustrations
- Organized by chapter
- Fast and scalable

---

## ⚙️ Tech Stack

- Python
- Streamlit
- OpenAI API

---

## 🔐 Setup

Add your OpenAI API key in Streamlit secrets:

OPENAI_API_KEY="your_api_key_here"
